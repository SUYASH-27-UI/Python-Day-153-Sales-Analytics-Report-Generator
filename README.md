# Python Day 153 - Sales Analytics & Report Generator

## Description
A Python application that analyzes sales records stored in a CSV file and generates a summary report.

## Features
- Read sales data from CSV
- Calculate total revenue
- Calculate total units sold
- Find the best-selling product
- Calculate product-wise revenue
- Generate a text report automatically

## Files
- `sales_analyzer.py` - Main Python program
- `sales.csv` - Sample sales data
- `sales_report.txt` - Generated report

## Requirements
- Python 3.x

## How to Run
Keep `sales_analyzer.py` and `sales.csv` in the same folder.

```bash
python sales_analyzer.py
```

- Data aggregation
